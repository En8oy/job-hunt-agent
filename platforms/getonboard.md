# Get on Board

Status: active (account required) — last verified 2026-10-14
URL: https://www.getonbrd.com
Account: required to apply. Stores CVs under "Your resumes" (getonbrd.com/resumes).
Type: job board (LatAm tech)

## Search
- Top search box or `getonbrd.com/jobs-<Tag>` (e.g. `jobs-Laravel`). A tag with no hits returns an empty page,
  not an error: try a couple of variants before concluding there's nothing.
- Many "remote" postings are country-restricted (Chile/Peru hybrid). Read the job's "Remote work policy"
  ("Fully remote / anywhere" vs a specific country) before applying.

## Apply
Multi-step wizard (Experience → Basic information → Questions → Preview), prefilled from the profile. Review each
screening answer, especially numeric "years with X" fields that can keep stale autofill values. Some LinkedIn
external applies route to `getonbrd.com/jobs/...`: that's this platform.
