# Jooble

Status: active — last verified 2026-10-08
URL: https://mx.jooble.org (country subdomain)
Account: not needed to browse.
Type: aggregator (redirects to the original source)

## Search
- Use the "Tipo de presencia" filter → "Empleo remoto"; the default mixes in on-site jobs.
- The first results marked "Sugerido" (sponsored) are usually generic recruiting funnels ("Remote dev positions
  $50/h"): treat with suspicion; focus on organic results.
- Skews toward .NET reposts; verify the stack.

## Apply
Clicking a result opens Jooble's page with an "Ir a <site>" button to the company site or ATS (Breezy HR,
Greenhouse...). Apply there; record `--platform jooble --ats <ats>`.
