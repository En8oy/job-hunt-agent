# Indeed

Status: active — last verified 2026-10-17
URL: https://mx.indeed.com (or the user's country domain) / https://www.indeed.com
Account: required. Stores only **one** CV at a time (profile.indeed.com → CV), no language split.
Type: job board (some postings redirect to the company site)

## Search
- Search each title with "Remote"/"Desde casa" and, if allowed, the user's cities. Sort by date.
- Glassdoor applications sync into Indeed's "My jobs" (myjobs.indeed.com/applied), so Indeed covers Glassdoor.

## Apply
- Indeed Apply uses the single stored CV; if the posting's language differs, upload the right PDF from `me/`
  in the form when it allows it.
- Screening questions: years per technology, salary, language level, commute. Answer from the profile.
- Confirmation emails come from "Postulación vía Indeed" / "Indeed Apply".
