# Upwork

Status: active (account + Connects required) — last verified 2026-10-01
URL: https://www.upwork.com
Account: required. No stored CV file (the profile is structured text).
Type: freelance marketplace

## Search
Search by skill; prefer clients with payment verified and real hiring history. Skip brand-new zero-history clients.

## Apply
- Proposals cost **Connects** (often 9–26 per job). Check "Available Connects" vs "Required Connects" on each job
  before writing a proposal; skip if the balance doesn't cover it. Never buy Connects; tell the user instead.
- A proposal is a message written on the user's behalf: draft it from the CV, and if `rules.ask_on_opinion_questions`
  is true, hand the draft back for approval instead of sending.
