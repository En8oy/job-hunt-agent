Type: aggregator (dev-focused)

## Search
Use the site search + remote type filter (`/jobs?q=<tech>&remote_type=fully_remote`); the `?tags=` parameter
doesn't filter. Check each listing's region tag: many remote roles exclude Latin America. Strong matches are
often cross-listed on LinkedIn or the company's careers page; apply there instead.
