# OCC Mundial (Mexico)

Status: active — last verified 2026-10-17
URL: https://www.occ.com.mx
Account: required. Stores a CV under "Mi CV" → "Archivo y enlaces".
Type: job board

## Search
- The URL remote filter (e.g. `/en-remoto/`) is unreliable. Use the **"Modalidad" dropdown → "Desde casa"** in
  the UI for remote-only results; otherwise on-site/hybrid postings slip in.
- For allowed on-site/hybrid cities, search by location (e.g. "Monterrey").

## Apply
- "Postularme" sends the CV stored in the profile; some postings add self-rated skill levels
  (Básico/Medio/Avanzado/Experto): rate honestly, they can be checked in interviews.
- Status updates appear under "Mis postulaciones" (e.g. "CV visto", "Finalizado" = closed/discarded) and in
  emails from OCC; "Finalizado" usually means rejected without an explicit message.
