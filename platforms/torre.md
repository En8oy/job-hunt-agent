# Torre

Status: active (account required) — last verified 2026-10-18
URL: https://torre.ai
Account: required (Torre profile = the CV). Recruiters message through Torre; notifications arrive by email.
Type: job board / matching

## Search
Use Torre's job search with the user's titles and "remote". Each posting shows a match score against the profile.

## Apply
- Applying uses the Torre profile; some postings add a skills pre-screening (rate a few skills) and recruiters may
  later ask for the CV through Torre messages: that becomes a task for the user to upload it.
- Check messages at torre.ai when an email says "X te envió un nuevo mensaje".
