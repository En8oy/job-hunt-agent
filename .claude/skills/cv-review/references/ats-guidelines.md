# ATS guidelines

Applicant tracking systems (Workday, Greenhouse, Lever, Ashby, iCIMS, Taleo, OCC/Computrabajo
parsers...) extract text from the CV and match it against the posting. What helps them:

## Format
- One column. No tables, text boxes, columns, images, icons, charts or skill bars.
- Contact info as plain text at the top (not in a page header/footer).
- Standard fonts, real text (never text inside images). The renderer handles this.
- Standard section names: Profile/Summary, Professional Experience, Projects, Education,
  Certifications, Skills, Languages (Spanish: Perfil, Experiencia Profesional, Proyectos,
  Educación, Certificaciones, Habilidades, Idiomas).
- Dates in a consistent format with month and year: "Feb 2023 – Sep 2026" /
  "feb 2023 – sep 2026". "Present" / "Actualidad" for current roles.
- Length: 1 page under ~5 years of experience, 2 pages max otherwise.

## Content
- Headline under the name = the target role, using the market's common title
  ("Full Stack Engineer", "Desarrollador Full Stack"), optionally plus one differentiator.
- Summary: 3–4 lines, years of experience, core stack, domain, one standout result.
- Each role: company · title, location (modality) — dates, one context line about the
  company if it's not well known, 3–6 bullets, then a "Stack:" line.
- Bullets: start with a strong past-tense action verb (Led, Built, Designed, Migrated,
  Reduced / Lideré, Construí, Diseñé, Migré, Reduje), say what and how, end with the
  result. Put a number in when the user gave one. Most important bullet first.
- Keywords: use the exact technology names postings use (PostgreSQL, not "Postgres DB";
  Node.js, React, AWS...). Mention each core technology inside a bullet where it was
  actually used, not only in a skills list.
- No photo, age, marital status, ID numbers or full street address (common in some
  Latin American CVs, but they hurt with international employers and add privacy risk).
  A city and country is enough.
- Remove filler ("responsible for", "team player", "hard-working") and buzzword lists.

## Honesty
- Never add a technology, title, number, employer or degree the user didn't state.
- Don't inflate titles ("Senior" only if that was the title or the user confirms it).
- If a gap or short stint is real, leave it; don't hide it by stretching dates.
